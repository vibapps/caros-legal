# caros-legal

Legal and support pages for **CarOS**, served by GitHub Pages.

| Page | URL |
| --- | --- |
| Privacy policy (Türkçe) | https://vibapps.github.io/caros-legal/ |
| Privacy policy (English) | https://vibapps.github.io/caros-legal/en/ |
| Support | https://vibapps.github.io/caros-legal/support/ |
| Terms of use | https://vibapps.github.io/caros-legal/terms/ |

Pages source: **main branch, root**. No build step — plain HTML, one inline stylesheet per
page, no fonts, no scripts, no third-party requests. A privacy policy served from a page that
phones home would be a poor joke.

These pages describe what the app actually does. If the app changes what leaves the device,
these change in the same release.
